# FocusCat

FocusCat 是住在 Mac 選單列上的番茄鐘。選單列上有一個小角色，旁邊寫著這一段還剩幾分鐘、你現在在做哪一件事。
點一下角色會打開面板，最上面是**現在做哪一件**。平常一次一件，真的要同時追好幾件，也可以一起放進「現在」。

番茄是 25 分鐘工作、5 分鐘休息，做滿四輪休息 15 分鐘。時間到不會自己開始下一段，要你自己按。

這個 repo 只放說明文件、回報範本，和每一版的安裝檔。程式碼不公開。

## 需要什麼

macOS 13（Ventura）以上。Apple Silicon（M 系列）和 Intel 都可以。不用另外裝別的東西，也不用會寫程式。

## 下載與安裝

1. 到 [Releases](https://github.com/mpragnarok/FocusCat/releases/latest) 下載 `FocusCat-<版本>.zip`，點兩下解壓縮。
2. 打開 Finder，左邊選「應用程式」，把 `FocusCat` 拖進去。
3. **第一次打開要按右鍵 → 打開**（不是點兩下）。

如果沒反應，或跳出視窗說沒辦法確認這個 App：

- 打開「系統設定 → 隱私權與安全性」，往下捲到「安全性」那一段。
- 會看到一行寫著 FocusCat 被阻擋。按旁邊的「仍要打開」，輸入電腦密碼。
- 回去再打開一次。

這只有第一次要做，之後點兩下就會開。

**為什麼會被擋**：這個 App 沒有付費的 Apple 開發者簽章，macOS 對這種 App 一律先攔下來。這跟 App 本身有沒有問題無關。
跳出來的視窗上寫什麼字，不同 macOS 版本不一樣，請以你螢幕上看到的為準。重點是找到「仍要打開」。

打開之後，螢幕最上面那排（時間旁邊）會出現一個小角色。沒有視窗是正常的，這個 App 只住在那裡。

## 升級到新版

有新版時，打開面板會在最下面看到一張小卡「FocusCat 有新版 X」，下面寫你現在用的是哪一版。

- **下載**：用瀏覽器打開那一版的下載頁。FocusCat 不會自己換掉自己。
- **看更新內容**：用瀏覽器打開那一版改了什麼。
- **這版先不要**：這一版不再提醒，下一版出來才會再出現。

下載之後，照上面「下載與安裝」的步驟再裝一次，把新的 `FocusCat` 拖進「應用程式」蓋掉舊的。
如果新版打開時又被系統擋下來，照第 3 步再做一次。
你的待辦和紀錄不放在 App 裡面，換掉 App 不會動到它們。

FocusCat 打開時看一次有沒有新版，之後每天看一次。它只問 GitHub「最新版是幾號」，不會送出你的任何資料。
不想要的話，到「設定 ▸ 一般」關掉「有新版時告訴我」，關掉之後就完全不連網。

也可以自己到 [Releases](https://github.com/mpragnarok/FocusCat/releases) 看有沒有新版。

## 回報問題

最簡單的方法是從 App 裡回報：

1. 打開「回報問題」視窗。有兩個入口，打開的是同一個視窗：
   - 面板上「現在」那張卡右上角的「⋯」，最下面的「回報問題…」。
   - 設定視窗（按 ⌘,）最底下那排按鈕的「回報問題」。
2. 填三欄：「發生什麼事」「本來預期什麼」「怎麼重現」。
3. 下面那一大格是會送出去的完整報告，送出前可以直接改。
4. 按「打開 GitHub」。瀏覽器會打開這裡的新 issue 頁，標題和內容都已經填好。你在 GitHub 按送出之前，什麼都還沒送出去。

報告會自動附上除錯資訊：版本、macOS、晶片、外掛有沒有開、最近的錯誤訊息。
送出前，App 會先把可能洩漏個資的字遮掉：

- 你的使用者資料夾路徑。
- 看起來像卡號、email、token 的字。
- 網址、主機名稱、IP 位址。
- 錯誤訊息裡帶到的待辦和會議名字。

你的待辦標題預設不會附上。要你自己勾「附上目前的待辦標題（可能含工作內容）」才會放進去。

報告太長、網址放不下時，網頁上只會放你填的三欄。完整的報告已經複製好了，在 GitHub 的內容欄貼上就好。

不想公開貼在 GitHub 的話，按「複製」貼到聊天，或按「存到桌面」把檔案傳給作者。內容一樣。

App 打不開、沒辦法從 App 回報時，可以直接在這裡 [開新 issue](https://github.com/mpragnarok/FocusCat/issues/new/choose)。

**安全性的問題請不要開公開 issue**，做法見 [SECURITY.md](SECURITY.md)。

## 你的資料在哪

都在你自己的電腦上。沒有帳號、沒有雲端、不會回報你怎麼使用它。

FocusCat 預設只連一個地方：每天問一次 GitHub 最新版是幾號。
另外兩種連網都要你自己在設定裡填好才會開始：行事曆網址（只讀進來，用來判斷你在不在開會），以及你自己裝的外掛。
